Is Arch hard to install? ▾

There are two paths. archinstall gives you a guided installer. The manual path is harder, but it is a feature.

Will it break? ▾

A rolling distro updated regularly is stable. Breakage comes from partial upgrades and ignoring pacman's output.

What is the AUR? ▾

A community repository of build recipes. Every package is a PKGBUILD, plain text you can read before you run it.
