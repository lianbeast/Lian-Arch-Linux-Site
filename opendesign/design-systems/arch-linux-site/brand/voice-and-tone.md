# Voice and Tone

## Register
Terminal-native, confident, zero sales. The distro speaks like a good man page: exact, imperative, no hedging. Sentences short. Fragments allowed.

- **Hero tagline:** "You. The machine. Nothing between."
- **Hero body:** "A lightweight, flexible, rolling-release Linux distribution for the self-directed. You build it. You own it. Nothing hides behind a curtain."
- **Features:** "Everything you need. Nothing you didn't ask for."
- **AUR (FAQ):** "Every package is a PKGBUILD — plain text you can read before you run it."

## Rules
- Address the reader as *you*. Second person always.
- Active voice. A button says what happens: "Download", "Read the wiki", "Copy".
- No exclamation marks. No emoji. No "welcome to".
- Numbers get verified or cut — this audience fact-checks.
- Errors are directions, not apologies. Show the failing command, not a sad illustration.
- Casing: sentence case everywhere. Section tags (eyebrows) can be uppercase with letter-spacing — that's a style treatment, not casing.

## About itself
Never "powerful", "amazing", "blazing fast". Facts and artifacts: `pacman -Syu`, 80,000+ AUR packages, PKGBUILD plain text, rolling release. Let the reader conclude the distro is powerful.
